4 How Agents Get Called (3 Methods)

Method 1: Claude Code CLI
Open terminal → cd ~/Desktop/Boldteq App/Pinzo → run claude

Say: "Use Quill to write the app store listing"
or: "Use Vex to fix this TypeScript error"

Claude Code reads Global CLAUDE.md → sees agent roster → invokes the right agent as a subagent automatically.

Status: Working after CLAUDE.md fix
Method 2: Polyglot Dashboard
Open localhost:5173 → go to Playground → select agent → type prompt → run

Uses the POST /api/playground/run endpoint.
Polyglot loads agent .md → runs via claude -p CLI → streams result back.

Status: Working
Method 3: Polyglot Orchestration
Open localhost:5173/orchestration → build workflow graph → connect agents → run

Visual drag-and-drop: chain multiple agents in sequence with dependencies.
E.g.: Nova → Arya → Koda → Sage (like Rex's modes, but visual).

Status: Working

5 How Discovery Works (Step by Step)

When you start a new Claude Code session in any project:

StepWhat HappensResult
1 Claude Code reads ~/.claude/CLAUDE.md (Global rules) Sees the agent roster table with all 12 agents, their filenames, and routing rules
2 Claude Code reads {project}/CLAUDE.md (Project rules) Sees project-specific patterns, stack, conventions
3 Claude Code scans ~/.claude/agents/*.md Discovers 12 global agents
4 Claude Code scans {project}/.claude/agents/*.md Discovers project-specific agents (e.g. widget-specialist in Pinzo)
5 You give a task Claude reads the routing rules from CLAUDE.md and picks the right agent
6 Claude invokes the agent as a subagent Agent gets its .md instructions as system prompt → executes the task

Rex describes the workflow order (Nova → Arya → Koda etc.) but can't automatically spawn agents in sequence in Claude Code CLI. You either manually invoke each one, or use Polyglot's Orchestration UI for true chaining.

Local Only — No Production Use
Everything runs on your Mac via claude -p CLI (your Claude subscription). Zero extra cost. Works perfectly for development. Not for merchant-facing features.
