# App Store Listing — Assets & Optimization

## Listing Components

### App Icon
- **Format:** JPEG or PNG
- **Dimensions:** 1200×1200px (square)
- **Style:** Bold colors, simple patterns, recognizable
- **Design:** Logo-focused, auto-rounded by Shopify
- **Avoid:** Text, screenshots, Shopify trademarks, transparency
- **Padding:** Include spacing so logo doesn't touch edges
- **File Size:** Keep <500KB

### App Title
- **Length:** Max 30 characters (recommended)
- **Format:** Start with brand name (not generic descriptor)
- **Good:** "MyBrand Email Manager" (brand + feature)
- **Bad:** "Email Manager" (too generic) or "The Best Email Automation" (keyword stuffing)
- **Consistency:** Must match Developer Dashboard app name

### Short Description (Tagline)
- **Length:** 30-50 characters (appears in search results)
- **Purpose:** Hook explaining core benefit
- **Example:** "Send targeted emails to boost sales"
- **Avoid:** Full feature list; focus on single key benefit
- **Test:** Does it explain what app does in one sentence?

### Long Description
- **Length:** 1-2 paragraphs of prose (not bullet list)
- **Purpose:** Explain app value, solve merchant pain point
- **Include:**
  - What problem does app solve?
  - How does app solve it?
  - What outcomes can merchant expect?
  - Key features (natural, not list)
- **Avoid:** Marketing hyperbole ("revolutionary", "industry-leading")
- **SEO:** Include keywords naturally (not forced)

### Category Selection
- **Primary Category:** Single most relevant category
- **Categories:** Analytics, Fulfillment, Marketing, Inventory, etc.
- **Structured Features:** Up to 25 features per category
- **Example Features:** "Email campaigns", "Automated flows", "A/B testing"
- **Search Keywords:** Up to 5 complete words (not partial matches)
  - ✅ Good: "email marketing" (complete phrase)
  - ❌ Bad: "email market" (partial) or "email marketing campaigns leads" (too many words)

### Pricing Information
- **BLOCKING:** Pricing must be clearly displayed
- **Model:** Specify subscription, usage-based, one-time, or free
- **Trial:** If offering free trial, disclose duration
- **Setup Fee:** If applicable, must be disclosed
- **Transparency:** No hidden fees or surprise charges

### Pricing Text Example
```
Free plan: Limited to 100 emails/month
Starter: $9.99/month for 1,000 emails
Pro: $29.99/month for 10,000 emails + automation
Enterprise: Custom pricing for 50,000+ emails

14-day free trial included with all paid plans
```

### Screenshots
- **Recommended:** 3-5 high-quality screenshots
- **Format:** 1600×900px or 1200×900px (landscape)
- **Content:** Show app interface in action (not marketing slides)
- **Captions:** Optional labels explaining what merchant sees
- **Order:** Show key flows: onboarding, main feature, results
- **Avoid:** Blurry images, marketing mockups, generic stock photos

### Video Asset
- **Length:** 2-3 minutes optimal (max 5 minutes)
- **Format:** MP4 or WebM
- **Focus:** Promotional (not instructional walkthrough)
- **Content:**
  - 25% screencast maximum (no talking-head videos)
  - Show app value proposition
  - Demonstrate key features
  - Include customer testimonial if available
- **Audio:** Clear, professional narration (optional)
- **Examples:** Before/after workflow, time-saving demonstration

### Support & Documentation Links

| Link | What to Provide |
|------|-----------------|
| FAQ | FAQ page answering common questions |
| Changelog | List of updates and new features |
| Support Portal | Help center or ticketing system |
| Tutorial | Onboarding guide or quick-start video |
| Developer Docs | API docs if app integrates with external services |

### Privacy & Trust
- **Privacy Policy Link:** (REQUIRED) Publicly accessible, linked in submission
- **Developer Contact:** Emergency contact info in Partner Dashboard
- **Company Background:** Optional; builds trust (1-2 paragraphs about company)
- **Testimonials:** Optional; merchant quotes add credibility

## Content Strategy

### Benefit-Focused Language
```
❌ FEATURE-FOCUSED (Avoid)
"App has email templates, scheduling, and analytics"

✅ BENEFIT-FOCUSED (Better)
"Send emails that convert with drag-and-drop editor, auto-send at peak times, and detailed performance tracking"
```

### Problem → Solution → Outcome
```
Title: "Email Marketing for Busy Shopify Owners"

Short: "Build email campaigns in minutes, not hours. Convert browsers into buyers."

Long: "Reach more customers without the complexity. Our drag-and-drop editor makes it easy to create beautiful emails, schedule them to send at peak times, and track what works. See 30% higher open rates on average."
```

### Keyword Strategy
- **Research:** What terms do merchants search for?
  - Use Google Keyword Planner, App Store search bar
  - Look at competitor apps' listings
- **Integration:** Weave keywords naturally
  - ❌ "Email marketing email automation email campaigns" (keyword stuffing)
  - ✅ "Email marketing automation for Shopify stores" (natural)
- **Location:** Keywords in title, short description, long description
- **Avoid Overuse:** Too many keywords → lower ranking

## App Store SEO Best Practices

### Title Optimization
- **Format:** [Brand/App Name] [Primary Feature] [Benefit]
- **Example:** "EmailBlast: Email Marketing for Shopify"
- **Avoid:** Generic ("Email App"), all caps, emoji
- **Test:** Does title answer "what is this app?"

### Meta Description (Short Description)
- **Length:** 30-50 characters (appears in search results)
- **Include:** Primary keyword, benefit statement
- **Example:** "Create email campaigns in minutes. 30% higher open rates."

### Category & Tags
- **Category:** Most relevant single category
- **Features:** 25 structured features (choose most important)
- **Keywords:** 5 complete words that describe app
  - "email marketing" ✅
  - "ecommerce automation" ✅
  - "customer engagement" ✅
  - "email market" ❌ (partial)
  - "send emails to customers in your Shopify store" ❌ (too long)

### Ranking Factors (Shopify App Store)
1. **Title & Description Match** — keywords match search
2. **Ratings & Reviews** — 4.5+ stars ranks higher
3. **Install Count** — popular apps rank higher
4. **External Traffic** — apps driven from outside rank higher
5. **Recency** — newer updates boost ranking temporarily
6. **Built for Shopify Badge** — gets priority search placement

### Improving Discoverability
- **Update Changelog:** Regular updates signal active maintenance
- **Drive External Traffic:** External traffic boosts "trending" ranking
- **Encourage Reviews:** More ratings improve visibility
- **Optimize Listing:** Clear description with keywords
- **Cross-Promote:** Link to app from blog, social media

## Trust Building Elements

### Professional Branding
- High-quality icon and screenshots
- Consistent visual style
- Clear, well-written descriptions
- Professional preview video

### Credibility Signals
- Company background or "About us"
- Customer testimonials or case studies
- Clear support contact information
- Link to company website
- Active development (regular updates)

### Documentation Quality
- Comprehensive help documentation
- Easy-to-follow tutorials
- Clear API documentation (if applicable)
- FAQ addressing common issues

### Support Commitment
- Responsive support team
- Clear support contact (email, portal, chat)
- Published response time commitment
- Regular updates and maintenance

## Listing Checklist

- [ ] Icon: 1200×1200px PNG/JPEG, recognizable, bold colors
- [ ] Title: <30 chars, starts with brand, matches Dashboard
- [ ] Short Description: 30-50 chars, single key benefit
- [ ] Long Description: 1-2 paragraphs, problem→solution→outcome
- [ ] Category: Single most relevant category
- [ ] Features: Up to 25 structured features (choose important)
- [ ] Keywords: 5 complete words (no partial matches)
- [ ] Pricing: Clearly specified (free/trial/subscription/one-time)
- [ ] Screenshots: 3-5 images, 1600×900px, showing app in action
- [ ] Video: 2-3 min, promotional, shows key benefits
- [ ] Support Links: FAQ, Changelog, Support Portal, Tutorial
- [ ] Privacy Policy: Public URL, linked, accessible
- [ ] Developer Contact: Updated in Partner Dashboard
