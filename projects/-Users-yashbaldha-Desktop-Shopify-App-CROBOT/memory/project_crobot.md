CROBOT is an AI-powered CRO (Conversion Rate Optimization) audit tool where users paste a URL and get instant conversion-boosting suggestions.

**Why:** Targets the $10.4B CRO market gap between free garbage tools and $500+/mo enterprise platforms. Affordable AI-native SaaS for SMBs at $29-$199/month.

**How to apply:** All UI/UX decisions should match Hotjar/Linear/Vercel quality. Marketing psychology matters — urgency, social proof, blurred premium content as upgrade triggers. The audit report is the "money page" that drives conversions.

**Tech Stack:** React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui + React Router v6 + Recharts + React Hook Form + Zod + Lucide Icons. Backend planned: Supabase + Railway (Puppeteer) + Claude API.

**Current State (March 2026):** ~40% built. Full Dashboard with KPIs, charts, quick wins. AI Agent system with 8 specialist agents (CROBOT Prime, Clarity, Converge, Shield, Prism, Pocket, Blitz, Quill), real-time collaborative workspace with progressive message delivery, task board, and new task creation flow. All main pages functional with realistic mock data. 70+ shadcn/ui components.

**Product Name:** CROBOT (may also be referred to as ConvertScan in strategy docs).

**7 CRO Pillars:** Value Proposition, CTA Effectiveness, Trust Signals, Visual Hierarchy, Mobile Experience, Content & Copy, Page Performance.

**Pricing:** Free ($0, 3 scans/mo), Pro ($49/mo, 50 scans), Agency ($199/mo, unlimited + white-label).
