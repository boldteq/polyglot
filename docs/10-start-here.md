# 👋 Start Here — Polyglot in plain English

> New here? Read this one page. No tech knowledge needed. It explains what this is, how it works, and the one thing you have to keep running.

---

## What is Polyglot?

Think of it as a **company of 66 AI specialists** that work for you — a backend builder, an architect, a bug fixer, a copywriter, a designer, and so on. Polyglot is the **office dashboard** where you watch them, manage them, and check that everything's healthy.

Two things make this team special:

1. **They do real work** — build apps, fix bugs, write copy, set up stores.
2. **They remember everything and get better every time.** Finish a project, and the whole team is a little smarter on the next one.

> **In plain English:** Polyglot isn't where the work happens (that's your code editor). Polyglot is the **control room** — like the dashboard in your car. The driving happens on the road; the dashboard tells you everything's running fine.

---

## The one big idea: a shared notebook

Your AI team shares **one notebook** of everything they've ever learned — every fix, every decision, every good example.

The magic part: the notebook is **searched by meaning, not exact words.** Ask *"how do I add a size chart"* and it finds the right note even if that note was titled *"product options."* It understands what you *mean*.

So the cycle is simple:

1. Before a job, the AI **checks the notebook.**
2. It does the work.
3. It **writes down what it learned.**
4. Next time, everyone starts smarter.

> **Note:** This is why the system keeps improving on its own. Nobody has to "train" it manually — every project quietly teaches the next one.

---

## Do I have to run or install anything?

Almost nothing. **One** small program needs to be running — **Ollama** (it's the free engine that powers the "search by meaning" notebook). Everything else starts and runs itself.

| Part | Who runs it? |
|---|---|
| **Ollama** (the memory engine) | **You** — keep it running (start the Ollama app) |
| The Polyglot dashboard | Itself — starts automatically, restarts if it crashes |
| The memory & the AI tools | Itself — already set up |
| The "learning" that happens overnight | Itself — runs on a schedule |

> **Tip:** If anything ever looks broken, 9 times out of 10 it's just Ollama not running. Open the Ollama app and you're back.

---

## Where do I look?

Open the dashboard in your browser:

```
http://localhost:3847
```

The most important screen is **System** (in the left menu). It's a **dashboard light** for the whole operation:

- 🟢 **Green** = that part is healthy and working.
- 🟡 **Amber** = needs a little attention (and it tells you what).
- 🔴 **Red** = something's down (and how to fix it).

If the top banner says **"Pipeline: Healthy"**, everything's good.
