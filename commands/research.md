Run competitive intelligence research on any product category or idea.

Usage: /research [product category or idea]

Examples:
- /research shopify size chart apps
- /research AI resume screening tools
- /research shopify bundle builder apps
- /research SaaS invoice automation for agencies

The `researcher` agent will:
1. Find top 3-5 competitors
2. Analyze features, pricing, and positioning
3. Read real user reviews (G2, Reddit, App Store)
4. Identify table-stakes features and USP gaps
5. Return a structured competitive intelligence report with v1 feature recommendations

Use this before starting any new build. Takes 5 minutes, saves weeks.
