2-day kill test for a raw SaaS idea. Fast validation before investing time.

Usage: /shape-only [1-3 sentence idea]

Examples:
- /shape-only tool that auto-generates API docs from TypeScript types
- /shape-only Shopify app for AI-powered product tagging
- /shape-only SaaS that monitors competitor pricing pages and alerts on changes

Pipeline (3 agents, ~2 hours):
  1. Scout — Pain score (1-10), ICP definition, distribution channel identification
     Kill gate: Pain <7 OR no distribution OR founder-only pain evidence
  2. Vex — Technical feasibility check (can this be built with current stacks?)
     Kill gate: Requires technology that doesn't exist or is unreasonably complex
  3. Sage — Compliance/security pre-check (any regulatory blockers?)
     Kill gate: Regulatory barrier too high for solo operator

Output: Scout Card with Go/No-Go recommendation.
If Go → run /validate-only to continue the pipeline.
If Kill → idea documented with reasoning. Move to next idea.

Expected hit rate: ~2 of 5 ideas pass Shape. This is normal and healthy.
