Start a new project from scratch using the Software Factory process.

Usage: /new [brief description of what to build]

Examples:
- /new shopify app that lets merchants add custom product badges
- /new saas tool for tracking influencer campaign ROI
- /new shopify app for bundle builder with upsell

This command activates the `factory` agent which will:
1. Load relevant memory and stack knowledge
2. Research 3-5 competitors in the space
3. Define architecture and v1 scope
4. Present a plan for approval
5. Build the complete v1 — production-grade and deployable
6. Run training extraction at the end

If no brief is provided, it will ask for one.
