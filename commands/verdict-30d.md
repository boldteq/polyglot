30-day post-launch decision: SCALE, PIVOT, or KILL. No middle ground.

Usage: /verdict-30d [project name]

Examples:
- /verdict-30d rankora
- /verdict-30d pinzo
- /verdict-30d convertscan

Prerequisites: Product launched and live for 30+ days.

Pipeline (3 agents):
  1. Orbit — Define/review metrics framework + pull current performance numbers
     (North star metric, activation rate, retention cohorts, KPI dashboard)
  2. Pulse — Synthesize user feedback (interviews, reviews, support tickets, public sentiment)
     (Top 3 pains, themed insights, pivot signals)
  3. Verdict — Binary decision with evidence
     Scores 5 criteria (activation, retention, market response, unit economics, sentiment)
     Average >4 = SCALE | 3-4 = PIVOT | <3 = KILL

Output:
- SCALE: 3x growth plan + next agents to dispatch
- PIVOT: New hypothesis + restart brief for Scout
- KILL: Post-mortem + lessons stored via Mira

Run again at 90 days for the definitive long-term verdict.
